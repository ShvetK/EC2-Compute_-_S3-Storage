## Getting Started

- I created a web application and deployed it into an Amazone EC2 instance. This application stores the file in an Amazon S3 bucket. Not only that but also modification and deletion are also possible. This is all possible using different API calls.

- Using this application I understand how to launch AWS Elastic Compute (EC2) instances, how to connect to an EC2 instance and provision it to support my web applications, the AWS Simple Storage Service (S3), and how to create a bucket, Experience working with AWS libraries, like boto3, that allow me to perform AWS operations such as creating a file on S3, and More experience building REST APIs.

### Prerequisites

Git needs to be installed on your machine.
The first step is to clone the tutorial repo in your machine using the below command.

```
git clone https://github.com/ShvetK/EC2-Compute_-_S3-Storage.git
```

You need the tools/libraries/software below to run this project on your machine.

- [VS Code](https://code.visualstudio.com/)
- [Node](https://nodejs.org/en/)
- [npm](https://www.npmjs.com/)
- [Express](https://reactjs.org/)
- [Axios](https://www.npmjs.com/package/axios)
- [Nodemon](https://nodemon.io/) (optional)

## Built With

- [Node](https://nodejs.org/en/) & [Express](https://reactjs.org/) - The back-end framework used to manage servers and routes.
